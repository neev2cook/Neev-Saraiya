Technical Report
1. Introduction

This project implements a 4‑wheel‑drive autonomous follower robot using a combination of HuskyLens vision‑based target tracking, Cytron MD10‑POT motor drivers, four Pepperl+Fuchs ML100 industrial optical sensors, four‑channel relay interface, and an Arduino‑compatible controller with hardware UART and I²C interfaces.

The software is structured around a Finite State Machine (FSM) that manages normal target tracking, target‑loss recovery, obstacle avoidance, reverse movement and emergency shutdown. The left‑side motors (front‑left and rear‑left) are controlled together, while the front‑right and rear‑right motors form the right drive pair.

2. Project Objective
  • Following a visually identified target using HuskyLens.
  • Maintaining an appropriate distance from the target.
  • Correcting direction according to the target's horizontal image position.
  • Detecting obstacles from four directions.
  • Automatically selecting an available direction for obstacle avoidance.
  • Reversing when required.
  • Searching for the target when visual tracking is lost.
  • Gradually changing motor speed to avoid abrupt acceleration/deceleration.
  • Entering an emergency‑stop condition when blocked or unsafe.

8. Safety Features
  • Four‑direction obstacle detection — independent optical sensors on front, rear, left, and right.
  • Obstacle avoidance — automatic alternate direction when the front path is blocked.
  • Rear safety check — reverse movement prevented when the rear sensor detects an obstacle.
  • Emergency stop — triggered when blocked on all sides or unsafe conditions occur.
  • Main drive‑bus isolation — the emergency state switches OFF the main drive relay.
  • Hazard warning — the horn remains energized during emergency stop.
  • Reverse warning — the reverse alarm is activated during reverse avoidance.
  • Target‑loss timeout — search mode entered after 1.5 seconds of target loss.
  • Motor ramping — gradual speed changes prevent abrupt acceleration.
